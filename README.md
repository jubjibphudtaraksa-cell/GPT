Vex GPT 🇹🇭

Vex GPT เป็นโปรเจกต์ AI ที่พัฒนาต่อยอดจาก Qwen2.5-1.5B-Instruct โดยมีจุดประสงค์เพื่อการศึกษา การทดลอง และการเรียนรู้เกี่ยวกับการพัฒนาโมเดลภาษา (LLM)

🎯 จุดประสงค์ของโปรเจกต์

* เรียนรู้การทำงานของโมเดล AI
* ศึกษาการฝึกโมเดลด้วย Fine-tuning
* ทดลองพัฒนา AI สำหรับภาษาไทย
* เรียนรู้การสร้าง AI ที่ช่วยเขียนโปรแกรม
* เปิดโอกาสให้ผู้สนใจนำไปศึกษาและพัฒนาต่อยอด

✨ ความสามารถ

* สนทนาภาษาไทย
* ตอบคำถามทั่วไป
* ช่วยเขียนและอธิบายโค้ด
* ทดลองใช้งานด้าน Python, HTML และ JavaScript
* รองรับการฝึกโมเดลเพิ่มเติม

📦 สิ่งที่ต้องเตรียม

* Python 3.10 ขึ้นไป
* หรือ Google Colab หรือสภาพแวดล้อม Python ที่รองรับ
* https://colab.research.google.com/drive/1GWdE-d1qa5s8tzcSD-mdiov1FvJd2M8p#scrollTo=5rnhRYi1pTHd
* อินเทอร์เน็ต
* GPU (แนะนำสำหรับการฝึกโมเดล)

🚀 วิธีติดตั้ง

1. ดาวน์โหลดโปรเจกต์

git clone https://github.com/jubjibphudtaraksa-cell/GPT

2. ติดตั้งไลบรารี

pip install unsloth ddgs

3. เข้าโฟลเดอร์โปรเจกต์

%cd GPT/thai-coder

เพิ่มข้อมูล Creator

!python add_creator.py

เริ่มฝึกโมเดล

!python finetune.py

หมายเหตุ: ตรวจสอบ Dataset และการตั้งค่าในไฟล์ก่อนเริ่มฝึกทุกครั้ง

📚 การใช้งานเพื่อการศึกษา

โปรเจกต์นี้จัดทำขึ้นเพื่อให้ผู้สนใจสามารถศึกษา ทดลอง และเรียนรู้กระบวนการพัฒนา AI ได้

ผู้ใช้งานสามารถนำแนวคิดและโค้ดไปศึกษาเพื่อทำความเข้าใจการทำงานของโมเดลภาษาและการ Fine-tuning ได้
